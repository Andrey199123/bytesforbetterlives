Foundations

Warm + bold, mint-led editorial

The 2026 redesign blends DECA's confident colour-blocking with a warm, human nonprofit voice. Signature colour is SY Glacier Mint; type is rounded-geometric (Gabarito) over a clean geometric body (Mulish). No serifs. It should read intentional and editorial — never templated.

Typography

Two families, three roles

Loaded via <link> in every page head (never CSS @import — that blocked first paint). Any new page shell copies the three font links. Gabarito sets blacker than the retired Nunito, so the whole display/label weight scale sits one notch down: 700 / 600 / 550 / 500.

Principles

The hard rules

  • Hover feedback signals clickability — and only that. A non-clickable element must never glow, lift, or change on hover. The lift (translateY + shadow) is reserved for whole-card links (.chapter-card, .chapter-leadership-card). Everything else is flat.
  • No decorative top/left lines on blocks. No accent spines or strips; accent is carried by a coloured numeral, chip, or data-driven pill.
  • Never render an empty section. Any data-driven section hides itself (display:none) when it has nothing to show — no bare headings over empty grids.
  • Mint is a wash, not a CTA fill. --green failed contrast for buttons; primary CTAs fill --green-dark with paper text.
  • Accent-dark sits a shade below accent. Every page keeps --accent-dark deeper than --accent so the kicker text layers under its underline bar.
  • Fonts load via <link>, not CSS @import. The three font links live in every page head — copy them into any new page shell.
