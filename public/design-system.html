Foundations

Warm + bold, mint-led editorial

The 2026 redesign blends DECA's confident colour-blocking with a warm, human nonprofit voice. Signature colour is SY Glacier Mint; type is rounded-geometric (Gabarito) over a clean geometric body (Mulish). No serifs. It should read intentional and editorial — never templated.

Typography

Two families, three roles

Loaded via <link> in every page head (never CSS @import — that blocked first paint). Any new page shell copies the three font links. Gabarito sets blacker than the retired Nunito, so the whole display/label weight scale sits one notch down: 700 / 600 / 550 / 500.

Accent

One accent, site-wide

Every page runs the same brand green: --accent / --accent-soft / --accent-dark are set once in :root and there are no body.page-* overrides. Accent drives kickers, underlines, hero tint, band washes, card hover and stat numerals. --accent-dark sits a shade deeper than --accent for the two-tone kicker layering.

Gold, coral and teal survive in :root as data colours, never as a page mood: the four-colour program-tile cycle, gold .pin-launching map pins, hollow coral .pin-outreach rings, status badges and --danger. They encode what a thing IS — reach for them only for that.

Components · Heroes

One green-ink field, photo or not

Two treatments, one colour. .home-hero and photo chapter heroes (.chapter-hero) lay the scrim over a real photograph; .hero-editorial — this page's own header — and .chapter-hero--editorial run the same field over a green-ink ground instead. No per-page hero colours.

  • The field. ink 86% + --green-deep at a 92° 72 → 66 → 62% falloff, plus a faint dot-grid and a top-left glow — both held down so the brightest pixel still clears 7:1 against paper copy.
  • Never a text-shadow. If hero type gets lost, deepen the wash. Photo chapter heroes also open with a scrim across the navbar band for exactly that reason.
  • Overlay navbar. Pages carrying body.nav-overlay run the bar fixed and transparent over the hero — .is-over-hero, added by initNavOverlay(). Solid is the default, so a blocked script can never hide the nav. Every hero on such a page re-adds --nav-height as top padding. This page has no navbar, so it skips the class.

Principles

The hard rules

  • Hover feedback signals clickability — and only that. A non-clickable element must never glow, lift, or change on hover. The lift (translateY + shadow) is reserved for whole-card links (.chapter-card, .chapter-leadership-card). Everything else is flat.
  • Corners are square, site-wide. Controls 4px, cards and surfaces 8px, icon chips 6px. Only true data pills (999px) and avatars (50%) keep their shape.
  • No decorative top/left lines on blocks. No accent spines or strips; accent is carried by a coloured numeral, chip, or data-driven pill.
  • Never render an empty section. Any data-driven section hides itself (display:none) when it has nothing to show — no bare headings over empty grids.
  • No text-shadows in any hero. The declarations are deleted, not overridden. If type is lost over a photo, deepen the hero wash.
  • Mint is a wash, not a CTA fill. --green failed contrast for buttons; primary CTAs fill --green-dark with paper text.
  • Accent-dark sits a shade below accent. --accent-dark is deeper than --accent so the kicker text layers under its underline bar. One green accent site-wide — gold, coral and teal are data colours, not page moods.
  • Fonts load via <link>, not CSS @import. The three font links live in every page head — copy them into any new page shell.
